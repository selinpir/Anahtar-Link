# Anahtar Link

Sık kullandığım web sitelerini ve internet kaynaklarını tek yerde toplamak için hazırladığım kişisel link sayfası.

Linkleri kullanım alanlarına göre farklı kategorilere ayırdım. Eğitim kaynakları, akademik içerikler, yazılım siteleri, videolar ve takip ettiğim diğer sayfalara buradan ulaşabiliyorum.

## Kategoriler

* Eğitim
* Akademik kaynaklar
* Yazılım ve web
* YouTube
* Dergiler
* Dizi ve film
* Sık kullandığım diğer siteler

## Kullanılan Teknolojiler

* HTML
* CSS
* GitHub Pages

## Canlı Site

https://selinpir.github.io/Anahtar-Link/

## Projenin Devamı

Bu proje başlangıçta kişisel bir link sayfası olarak hazırlandı.

Yeni sürümde bağlantıları elle HTML'e eklemek yerine tarayıcı üzerinden kaydedilebilen, kategorilere ayrılabilen ve farklı sitelerdeki bookmark'ları tek yerde yöneten bir uygulamaya dönüştürmeyi planlıyorum.
